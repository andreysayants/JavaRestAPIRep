# Java REST API Test Automation Framework

Пет-проект по автоматизации тестирования REST API с полным циклом: от локального запуска и упаковки в Docker до интеграции в CI/CD-пайплайн Jenkins и генерации наглядной отчетности в Allure.

## 🎯 О проекте
Проект создан как демонстрация актуального стека и архитектурных подходов для автоматизации бэкенд-тестирования:
* **Чистая архитектура:** разделение логики запросов, моделей данных, проверок и тестовых сценариев.
* **Готовность к CI/CD:** тесты изолированы в Docker-контейнерах и готовы к запуску по тегам или расписанию в Jenkins.
* **Прозрачная отчетность:** подробное логирование всех HTTP-запросов, ответов и шагов выполнения в Allure Report.

## 🛠 Технологический стек
* **Язык и сборка:** Java, Maven (`pom.xml`)
* **Тестирование API и ассерты:** REST Assured, JUnit 5
* **Отчетность:** Allure Framework (с интеграцией `AllureRestAssured`)
* **Контейнеризация:** Docker (`Dockerfile`, `docker-compose.yml`)
* **CI/CD:** Jenkins (`Jenkinsfile`)

## 📂 Структура проекта
```text
├── src/                # Исходный код фреймворка и API-тесты
├── allure-report/      # Сгенерированный HTML-отчет о прохождении тестов
├── Dockerfile          # Инструкция сборки образа с тестовым окружением
├── docker-compose.yml  # Оркестрация запуска тестов в контейнере
├── Jenkinsfile         # Декларативный пайплайн для запуска в Jenkins
└── pom.xml             # Зависимости Maven и конфигурация плагинов
```

## 🚀 Способы запуска

### 1. Локальный запуск через Maven
Запуск всех тестов и генерация сырых результатов:
```bash
mvn clean test
```
Запуск тестов по конкретному тегу (например, `smoke`):
```bash
mvn clean test -Dgroups=smoke
```
Просмотр Allure-отчета локально:
```bash
allure serve target/allure-results
```

### 2. Запуск в Docker
Сборка и прогон тестов в изолированном контейнере через Docker Compose:
```bash
docker-compose up --build
```

### 3. Запуск в Jenkins
В корне репозитория находится `Jenkinsfile`, настроенный для автоматического прогона тестов в пайплайне (с поддержкой выбора тегов/параметров запуска и публикацией отчетов).
